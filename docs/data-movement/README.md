# Enterprise Data Movement Program

This package defines the no-code product plan and target architecture for importing,
exporting, migrating, and synchronizing Time Motor Sales data through the Command
Control Center.

## Recommended planning branch

`codex/plan-enterprise-data-movement`

Use a separate implementation branch after this package is approved:

`codex/feature-enterprise-data-movement-foundation`

- [Migration control catalog](MIGRATION_CONTROL_CATALOG.md)

## Decision boundary

This is a planning package only. It does not enable an import, export, connector,
scheduled feed, direct database load, or production data migration.
