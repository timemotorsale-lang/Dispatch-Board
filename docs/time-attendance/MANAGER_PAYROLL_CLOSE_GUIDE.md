# Manager and payroll close guide

## Attendance Manager

1. Open **Manager Review** in calm mode; use high-volume mode only when density helps.
2. Resolve blocking items first. Inspect original and proposed evidence before a correction decision.
3. Never bulk-resolve exceptions or sensitive corrections. Apply approved corrections individually; card reprojection creates a new version.
4. Return disputed or incomplete cards with a clear reason.
5. Approve only a clean card with a confirming employee attestation bound to the same version and checksum. Never approve your own card.
6. For protected leave, plan coverage from redacted information; Leave Administration owns the final private decision.

## Payroll close

1. Confirm the configured pay period and complete active roster.
2. Clear open sessions, missing cards, blocking exceptions, corrections, leave decisions, attestations and manager approvals.
3. Lock with the dedicated period authority. Lock is atomic and binds exact card versions.
4. Create the CSV handoff file. The stored bytes, lines, control totals and checksum are the reproduction source.
5. Download for controlled review. No provider transmission or payment is claimed.
6. Record acknowledgment, rejection or reconciliation only from real evidence.
7. Use controlled reopen with a reason when changes are required. Reopened cards are no longer payroll-ready.
8. Complete the parallel reconciliation before any pilot approval.
