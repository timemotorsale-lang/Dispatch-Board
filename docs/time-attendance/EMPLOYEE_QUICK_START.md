# Employee quick start

1. Open **Time & Attendance → Today**. Confirm your current state and last accepted punch.
2. Use the single matching action: **Clock in**, **Start/End meal**, **Start/End paid rest**, or **Clock out**. Attendance does not start repair labor.
3. After a timeout, refresh state before trying again. A safe duplicate retry is labeled; do not create a correction just because the screen was slow.
4. Use **My Time** to review totals, exact punch history, rest/meal evidence and open exceptions.
5. If a punch is wrong or missing, submit a correction with the exact proposed value and explanation. The original remains preserved.
6. Request PTO, ESST or unpaid time in My Time. Put protected ESST details only in the private reason field.
7. Attest only the exact card version shown. Choose **Dispute** when it is not accurate.
8. Internal inbox messages are workspace records only; they do not claim email or text delivery.

If capture is unavailable, note the real time and contact the Attendance Manager. Do not repeatedly click or share protected leave details with an ordinary manager.
