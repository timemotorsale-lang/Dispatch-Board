# Appointment Resource Action Reason Fields Contract

**Work package:** EAPT-029O  
**Status:** Implemented as initial board-visible resource action reason fields  
**Verified:** 2026-07-06

## Purpose

This contract adds explicit audit-note capture to the Appointment Board resource actions that represent exceptions or meaningful operational changes.

Before this slice, warning override, release, and replacement actions submitted valid reason notes, but those notes were generated by the board. The user did not have a dedicated place to document the business reason. The board now displays targeted reason fields directly in Resource Planning before these actions can be submitted.

## User Flow

From `/appointments`:

1. User selects a persisted live appointment and opens Resource Planning.
2. When a proposed resource candidate has warning-level availability, the board shows **Manager warning reason** before **Override Warning** can be submitted.
3. When a reservation is `HELD` or `COMMITTED`, the board shows **Release reason** before **Release Reservation** can be submitted.
4. When a reservation is `HELD`, the board shows **Replacement reason** before **Replace Reservation** can be submitted.
5. The board combines the operational context with the user-entered reason and sends the full reason note to the existing server APIs.
6. After a successful action, the specific reason field is cleared.

## Enterprise Controls

- Warning override reason notes are required before warning override submission.
- Release reason notes are required before held/committed reservation release.
- Replacement reason notes are required before held reservation replacement.
- Reason notes are captured at the point of action, not after the fact.
- Existing server-side reason-code and reason-note enforcement remains unchanged.
- Existing authorization, expected-version, state, and availability controls remain unchanged.
- The submitted reason note includes both:
  - system-generated operational context
  - user-entered explanation

## Board Fields

| Action | Field | Reason code |
| --- | --- | --- |
| Override Warning | Manager warning reason | `RESOURCE_WARNING_OVERRIDDEN` |
| Release Reservation | Release reason | `RESOURCE_RESERVATION_RELEASED` |
| Replace Reservation | Replacement reason | `RESOURCE_RESERVATION_REPLACED` |
