# CRM Next — Information Architecture

## Primary navigation

Command Center; Customers; Needs Attention; Pipeline; Appointments; Cases; Intelligence; Reports; CRM Settings.

Customer 360 appears when a customer opens; it is not a redundant main-menu destination.

## Command Center

Default landing page and system of action. Above the fold: Needs Attention; My Work Today; Today's Appointments; Pipeline movement; Risk/Opportunity intelligence; manager team-response indicators when applicable. It must not become a passive chart dashboard.

## Customer 360

### Overview

Situation-aware summary, open items, relationship context, next best action.

### Sales

Leads; Appointments; Test Drives; Deals.

### Ownership

Vehicles Purchased; BHPH/Financing; Payments.

### Support

Service/Repairs; Rentals/Loaners; Documents/Titles; Customer Issues; Insurance Claims.

### Activity

Communications; Tasks; Complete Activity Timeline.

## Universal actions

Visible: Call | Text | Email | Appointment | Task | More. More: Create Deal; Start Test Drive; Record Payment; Create Service Case; Rental/Loaner; Document/Title; Customer Issue; Insurance Claim; Add Note.

## Needs Attention

A prioritized work queue. Each item shows customer, attention type, severity, explanation, age/deadline, owner, recommended next action, and Attend.

## Pipeline

Default stages: New Lead → Contacted → Appointment → Test Drive → Negotiating → Pending → Sold/Lost.

## Cases

Common resolution framework for Customer Issues, Titles/Documents, Service, Insurance, Payment/BHPH attention, Rentals/Loaners.

## Global search

Search customer name, phone, email, VIN, stock number, vehicle, deal reference, and plate when stored. Group results by useful context rather than forcing module selection first.
