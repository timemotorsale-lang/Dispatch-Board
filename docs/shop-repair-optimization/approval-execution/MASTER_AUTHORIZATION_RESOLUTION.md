## Required findings

Before any implementation authorization, the approving authorities must find that:

- AE-0 authority and separation requirements are valid;
- every applicable decision has an attributable disposition;
- each safe deferral has an enforceable excluded scope and safe manual path;
- exact people, locations, lanes, calendars, skills, resources, safety, financial, privacy, data and integration controls exist;
- applicable tabletop cases pass and evidence is accepted;
- no uncontained critical safety, authorization, financial, quality, privacy, fairness or data gap remains;
- implementation scope is a named slice with tests and rollback, not all algorithms at once.
