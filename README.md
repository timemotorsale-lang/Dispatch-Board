# Time Motor Sales Dispatch Board

This repository contains the v0.2.0 identity, roles, and permissions milestone for the Time Motor Sales Dispatch Board MVP.

The project is a Next.js + TypeScript web app with a PostgreSQL + Prisma baseline, local development users, server-side session auth, protected routes, and reusable permission helpers for later dispatch workflows.

Setup instructions live in [`docs/SETUP.md`](docs/SETUP.md).
